# Telegram Tasks Bot

Bot Telegram (telebot) për menaxhim detyrash — butonat: shto detyrë, fshi detyrë, shiko detyrat. Demoja web simulon të njëjtin flow në browser (ruajtje lokale).

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

## 📁 Struktura
- `index.html — faqja showcase (Live Demo + Kodi Burim)`
- `demo/index.html — demo web (task manager simulim)`
- `original/tasks.py — kodi origjinal Python (i paprekur)`
- `README.md, PROVENANCE_LICENSE.txt`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python + `pip install pyTelegramBotAPI` dhe token-in e botit. Ekzekuto me `python tasks.py` — boti përgjigjet në arabisht me 3 butonat kryesorë.
